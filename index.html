How to Study This Guide

  • Order matters: M1→M2 before any valuation module; M3 before M4–M6; M6 before M7–M8.

    10 weeks at 6–8 hrs/wk: M1–2 (wks 1–2), M3–5 (wks 3–4), M6 (wk 5), M7 (wks 6–7), M8 (wk 8), M9 (wk 9), M10 (wk 10).

  • Every formula here should also exist in an Excel file you built.

    Rebuild: 3-statement model, DCF, comps sheet, accretion/dilution, paper LBO. Push them to this repo under /deliverables.

  • Interview drills: answer OUT LOUD before opening the toggle.

    Reading an answer feels like knowing it. Saying it is knowing it.

  • Pair with THE DESK game and RX Academy for the restructuring side.

    RX + IB together is exactly the Harris Williams / PWP conversation.
